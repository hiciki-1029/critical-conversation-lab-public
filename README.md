# 关键对话 Lab · Ciki

为下一次难开口的谈话，先练一遍。这个个人版可以作为对话练习工作台的搭建参考。

## 本地跑一遍

需要 Python 3.10 或更高版本，无需安装依赖。在项目根目录运行：

```sh
python3 server.py --offline
```

访问 http://127.0.0.1:8080/。默认是离线演练，有三个虚构场景和脚本式回应。练习目标与对话仅在当前页面使用，你主动保存的下一步动作存于当前浏览器，可在页面底部清除。

如果只需要分享离线体验，可以将 `index.html`、`style.css` 和 `lab.js` 放到静态站点。三份文件应放在同一目录。

## 产品逻辑

| 阶段 | 练习者在做什么 | 实现 |
| --- | --- | --- |
| 准备场景 | 选一个虚构场景，写下这次想练的具体目标 | 在开始时记录目标，带入对话和复盘 |
| 模拟对话 | 按自己实际会说的方式接话 | 离线模式使用预写回应，AI 模式按上下文接话 |
| 成长复盘 | 回看一句自己说过的话，决定下次想试的动作 | 用发言序号找回原话，动作由本人确认后保存 |

想改成自己的版本，可以先在 `lab.js` 改场景和离线示例，在 `server.py` 改角色与教练的提示词。

## 可选的 AI 演练

在启动前，通过终端环境或密钥管理工具提供 `OPENAI_API_KEY` 和 `LAB_MODEL`。模型须支持 Chat Completions 的 JSON 对象输出。运行 `python3 server.py`，页面会显示「AI 演练」。

此模式会向配置的 OpenAI 服务发送场景、练习目标和对话。请使用虚构信息。密钥由本地服务读取。服务绑定回环地址，适合个人在本机运行。对外提供 AI 练习服务时，需要另行接入身份验证、使用限额和数据处理设置。

## 验证与许可

运行 `python3 -m unittest discover -s tests` 和 `node --test tests/lab.test.cjs` 可验证主要交互和本地 API，测试无需网络或 API 密钥。
